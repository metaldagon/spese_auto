🔗 Configura Google Drive
I dati vengono salvati in Spesauto/spese_auto.json sul tuo Drive e sincronizzati su tutti i dispositivi.
Serve un Client ID Google gratuito (operazione una-tantum, ~5 minuti).
1. Vai su console.cloud.google.com → Nuovo progetto SpesAuto
2. API e Servizi → Libreria → abilita Google Drive API
3. Credenziali → Crea → ID client OAuth 2.0 → Applicazione web
4. In URI JavaScript autorizzati aggiungi: https://tuonome.github.io
5. Copia il Client ID e incollalo qui sotto → Salva → Connetti Drive
